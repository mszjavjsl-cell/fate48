# 정밀 만세력 로컬 MVP

배포판: [https://mszjavjsl-cell.github.io/fate48/](https://mszjavjsl-cell.github.io/fate48/)

## 실행

Node.js 20 이상에서 다음 명령을 실행한다.

```powershell
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(기본값 `http://localhost:5173`)를 브라우저에서 연다.

프로덕션 빌드와 테스트는 다음 명령으로 확인한다.

```powershell
npm test -- --run
npm run build
```

## 현재 구현 범위

- `yyyymmddhhmm` 형식의 12자리 생년월일시분 입력
- 양력·음력 선택과 음력 윤달 입력, 양력 환산일 표시
- 성별 입력과 대한민국 표준시 기준 계산
- 원국 천간·지지의 음양오행 색상과 십신·십성 한글 표시
- 입춘·12절 경계를 적용한 연주와 월주
- 현지 민간시 00:00 일주 경계와 23:00–00:59 자시
- 연간 음양과 성별에 따른 대운 순행·역행
- 초 단위 절입시각과 `3일 = 1년` 환산에 따른 첫 교운
- 10개 대운과 각 대운별 10개 세운
- 연도와 연 나이를 동시에 표시하는 대운·세운 선택 UI
- 기준 절기, 절입시각, 기산기간, 첫 교운과 계산 프로필 표시

진태양시, 해석 문장, 회원·저장 기능은 아직 포함하지 않는다.

## 계산 프로필

- 프로필: `kr-traditional-v1-draft` / `0.1.0`
- 절기 공급자: `tyme4ts 1.5.3`의 수성천문력 계열 계산
- 절기 원시각: 라이브러리가 반환하는 고정 UTC+8 시각을 instant로 변환
- 입력·사용자 표시: 대한민국 표준시(`Asia/Seoul`) 고정
- 첫 교운 덧셈: 현지 달력의 년 → 월 → 일 → 시 → 분 → 초
- 절입 순간과 출생 순간이 같을 때: 엄격히 다음 절 또는 이전 절을 선택
- 세운 나이: `해당 연도 - 출생 연도 + 1`의 연 나이

`test-vectors/golden-cases.v0.1.json`의 절입 자료는 아직 `provisional`이다. 1989년 망종은 그 벡터가 `02:05:14 KST`를 쓰지만 현재 공급자는 `02:05:13 KST`를 반환한다. 이 1초 차이는 전통 환산에서 교운시점 2분 차이로 확대되어 현재 앱은 `1997-04-17 11:41 KST`를 계산한다. 권위 절입 자료를 잠글 때 공급자 버전과 골든 벡터를 함께 확정해야 한다.

## 주요 파일

- `src/domain/manse.ts`: 전체 계산 조정과 출력 모델
- `src/domain/terms.ts`: 절기 공급자 시각과 시간대 변환
- `src/domain/ganji.ts`: 원국·시주·십신 표시 계산
- `src/domain/luck.ts`: 기산기간과 첫 교운 계산
- `src/components/`: 입력, 원국, 대운, 세운 UI
- `src/styles.css`: 모바일 우선 반응형 디자인
- `scripts/e2e-smoke.mjs`: 모바일·데스크톱 브라우저 스모크 테스트

## 검증 상태

- 도메인 및 상호작용 테스트 18개
- 390×844 모바일과 1280×900 데스크톱에서 본문 가로 넘침 없음
- 대운 선택 → 세운 목록 교체 → 세운 상세 선택 확인
- 브라우저 콘솔 오류 없음
