# 만세력 계산 엔진 규칙 명세서 v0.3.0-draft

## 1. 목적

이 문서는 사주 해석과 분리된 **재현 가능한 만세력 계산 엔진**의 규칙을 정의한다. 같은 입력, 계산 프로필, 천문 데이터 버전을 사용하면 구현 언어와 실행 환경이 달라도 같은 결과가 나와야 한다.

이 문서에서 `MUST`, `MUST NOT`, `SHOULD`, `MAY`는 각각 필수, 금지, 권장, 선택을 뜻한다.

## 2. v1 범위

### 포함

- 양력 출생일시 입력
- IANA 시간대와 UTC 변환
- 24절기 절입시각 조회 또는 천문 계산
- 입춘 기준 연주
- 12절 기준 월주
- 일주와 시주
- 대운 순행·역행
- `3일 = 1년` 방식의 첫 교운시점
- 이후 10년 단위 대운
- 계산 과정과 사용한 규칙의 감사 로그

### 후속 버전

- 균시차를 포함한 진태양시 선택 프로필
- 23시 일진 변경 방식
- 해외 역사 시간대의 확대 검증
- 세운·월운·일진 및 해석

## 3. 핵심 설계 원칙

1. 계산 엔진과 해석 엔진을 분리한다.
2. 모든 내부 시각은 `UTC instant`로 보관하고 표시 및 달력 연산 때 지정 시간대로 변환한다.
3. 단순한 숫자 UTC 오프셋 대신 IANA 시간대 ID를 입력받는다.
4. 절입시각, 시간대 데이터, 계산 프로필의 버전을 결과에 기록한다.
5. 중간값을 숨기지 않는다. 순행 판정, 선택 절기, 시간차, 환산기간을 모두 반환한다.
6. 부동소수점으로 기간을 계산하지 않는다. 초 또는 그보다 작은 정수 단위를 사용한다.

## 4. 기본 계산 프로필

프로필 ID는 `kr-traditional-v1-draft`로 한다.

| 항목 | v1 기본값 |
|---|---|
| 역법 | proleptic Gregorian calendar |
| 시간대 | 입력된 IANA time zone |
| 한국 기본 예시 | `Asia/Seoul` |
| 출생시각 보정 | 출생지 경도에 따른 지방평균시 보정 |
| 한국 표준자오선 | 동경 135도 |
| 균시차 기반 진태양시 | 적용하지 않음 |
| 연주 경계 | 입춘 절입 순간 |
| 월주 경계 | 12절의 절입 순간 |
| 일주 경계 | 현지 민간시 00:00 |
| 자시 구간 | 23:00:00 이상 01:00:00 미만 |
| 대운 순역 | 년간 음양과 성별 |
| 대운 기준 절기 | 순행은 다음 절, 역행은 이전 절 |
| 기산 비율 | 실제 3일 = 대운 1년 |
| 기산 달력 | 1년 360일, 1개월 30일 |
| 기산기간 덧셈 | 현지 달력의 년 → 월 → 일 → 시 → 분 → 초 순서 |
| 이후 대운 | 첫 교운의 현지 달력시각에서 10년씩 |

`draft` 프로필은 절입 데이터 공급원과 일주 기준 상수가 확정되기 전까지 제품 정답으로 간주하지 않는다.

## 5. 입력 계약

```json
{
  "calendar": "gregorian",
  "date": "1989-05-13",
  "time": "07:15:00",
  "timeZone": "Asia/Seoul",
  "sex": "female",
  "location": { "name": "서울", "longitude": 126.978 },
  "latitude": null,
  "profileId": "kr-traditional-v1-draft"
}
```

### 검증 규칙

- `date`는 `YYYY-MM-DD` 형식으로 받는다.
- `time`은 초까지 받을 수 있으며 생략할 수 있다. 생략하면 출생시각 미상으로 처리하고 임의의 시주를 생성하지 않는다.
- 존재하지 않는 현지시각(DST gap)은 오류로 처리한다.
- 중복되는 현지시각(DST overlap)은 오프셋 또는 fold 선택이 없으면 오류로 처리한다.
- `sex`는 v1에서 `male` 또는 `female`이다. 순역 규칙을 적용할 수 없는 값은 명시적 오류로 처리한다.
- 한국 출생지는 경도를 필수로 보존하며 시주 구간 판정에 지방평균시를 사용한다.
- 경도 보정초는 `round((출생지 경도 - 135) × 240)`이다.
- 균시차는 적용하지 않으므로 이 보정시각을 진태양시라고 부르지 않는다.

## 6. 출력 계약

```json
{
  "profileId": "kr-traditional-v1-draft",
  "profileVersion": "0.3.0",
  "ephemeris": {
    "provider": "unlocked",
    "version": "unlocked"
  },
  "normalizedBirth": {
    "localDateTime": "1989-05-13T07:15:00+09:00",
    "solarLocalDateTime": "1989-05-13T06:42:55+09:00",
    "longitudeCorrectionSeconds": -1925,
    "timeKnown": true,
    "utc": "1989-05-12T22:15:00Z",
    "timeZone": "Asia/Seoul"
  },
  "pillars": {
    "year": "己巳",
    "month": "己巳",
    "day": null,
    "hour": null
  },
  "luckCycle": {
    "direction": "forward",
    "basisTerm": "芒種",
    "termInstantLocal": "1989-06-06T02:05:14+09:00",
    "civilElapsedSeconds": 2055014,

    "firstTransitionLocal": "1997-04-17T11:43:00+09:00"

```

실제 출력에서는 모든 사주 네 기둥을 채워야 한다. `null`은 아직 정답 상수가 잠기지 않은 이 문서 예시에서만 사용했다.

## 7. 절기 정의

24절기는 태양의 시황경(apparent geocentric ecliptic longitude)이 15도 간격의 목표 황경에 도달하는 순간으로 정의한다.

대운 및 월주 경계에 사용하는 12절은 다음과 같다.

| 절 | 목표 황경 | 월지 |
|---|---:|---|
| 입춘 | 315° | 寅 |
| 경칩 | 345° | 卯 |
| 청명 | 15° | 辰 |
| 입하 | 45° | 巳 |
| 망종 | 75° | 午 |
| 소서 | 105° | 未 |
| 입추 | 135° | 申 |
| 백로 | 165° | 酉 |
| 한로 | 195° | 戌 |
| 입동 | 225° | 亥 |
| 대설 | 255° | 子 |
| 소한 | 285° | 丑 |

### 절입 데이터 요구사항

- 천문 계산 결과는 최소 1초 정밀도로 저장한다.
- 데이터에는 UTC 시각, 계산 라이브러리 또는 역서, 버전, 천문 모델을 기록한다.
- 외부 표의 시각을 사용할 경우 원문 시간대가 명시되지 않으면 제품 정답 데이터로 채택하지 않는다.
- 동일 instant를 중국 표준시와 한국표준시로 표시하면 각각 UTC+08:00과 UTC+09:00이므로 한 시간 차이가 난다. 숫자 시각만 복사하면 안 된다.
- 절입 데이터가 바뀌면 테스트 벡터와 계산 결과의 데이터 버전을 함께 올린다.

## 8. 사주 원국 계산

### 8.1 연주

- 출생 instant가 해당 현지 연도의 입춘 instant 이전이면 전년 간지를 사용한다.
- 입춘 instant 이상이면 해당 연도 간지를 사용한다.
- 경계 비교는 `birthInstant < lichunInstant`처럼 instant 단위로 한다.

연간 인덱스의 기준은 구현 전에 검증 사례로 잠근다. 일반식 예시는 `(gregorianYear - 4) mod 60`이며 0은 `甲子`지만, 입춘 이전에는 대상 간지년을 1 감소시켜야 한다.

### 8.2 월주

- 월지는 12절의 절입 instant로 바뀐다.
- 입춘부터 寅월, 경칩부터 卯월 순으로 진행한다.
- 월간은 연간에 따른 오호둔(五虎遁)을 적용한다.

| 연간 | 寅월 월간 |
|---|---|
| 甲·己 | 丙 |
| 乙·庚 | 戊 |
| 丙·辛 | 庚 |
| 丁·壬 | 壬 |
| 戊·癸 | 甲 |

### 8.3 일주

- v1 기본 일 경계는 현지시각 00:00이다.
- 경도 보정시각이 날짜 경계를 넘더라도 일주는 입력 민간시의 날짜를 유지한다.
- 검증된 기준일 하나의 일주 인덱스와 날짜 차이를 이용해 계산한다.
- 기준일과 Julian day 변환 상수는 최소 두 개의 독립적인 역서로 확인한 뒤 `locked` 상태로 변경한다.
- 23시 일진 변경은 별도 프로필에서만 지원한다.

### 8.4 시주

- 출생시각이 없으면 시주를 생성하지 않으며 결과 원국은 연주·월주·일주 3개만 반환한다.
- 시주 구간 판정에는 출생지 경도로 보정한 지방평균시를 사용한다.
- 한국 표준자오선 135도보다 서쪽이면 시각을 빼고 동쪽이면 더한다.
- 예: 서울 126.978도, `1986-04-02 15:25`는 `-32분 05초`를 적용해 약 `14:52:55`가 되므로 未시다.
- 시지는 2시간 단위를 사용한다: 子 23:00–00:59, 丑 01:00–02:59, ..., 亥 21:00–22:59.
- 시간 구간은 반개구간으로 구현한다. 예: 辰시는 `[07:00:00, 09:00:00)`이다.
- 시간은 일간에 따른 오서둔(五鼠遁)을 적용한다.

| 일간 | 子시 시간 |
|---|---|
| 甲·己 | 甲 |
| 乙·庚 | 丙 |
| 丙·辛 | 戊 |
| 丁·壬 | 庚 |
| 戊·癸 | 壬 |

## 9. 대운 계산

### 9.1 순행·역행

양간은 `甲 丙 戊 庚 壬`, 음간은 `乙 丁 己 辛 癸`이다.

| 조건 | 방향 |
|---|---|
| 양년 남성 | 순행 |
| 음년 여성 | 순행 |
| 음년 남성 | 역행 |
| 양년 여성 | 역행 |

판정에는 **입춘 기준으로 계산된 연주의 천간**을 사용한다. 단순히 양력 연도 끝자리만 사용하면 안 된다.

### 9.2 기준 절 선택

- 순행: 출생 instant보다 엄격히 뒤에 있는 다음 12절
- 역행: 출생 instant보다 엄격히 앞에 있는 이전 12절
- 출생 instant가 절입 instant와 정확히 같을 때의 정책은 아직 미확정이다. v1 잠금 전 `inclusive-current-term` 또는 `strict-adjacent-term` 중 하나를 테스트로 고정해야 한다.

### 9.3 시간차

```text
순행 elapsed = nextTermInstant - birthInstant
역행 elapsed = birthInstant - previousTermInstant
```

두 instant를 같은 시간축에서 빼야 한다. 결과는 음수가 될 수 없다.

### 9.4 `3일 = 1년` 환산

전통식 가상 달력은 1년 360일, 1개월 30일이다.

```text
actual 3 days  = luck 1 year
actual 1 day   = luck 4 months
actual 1 hour  = luck 5 days
actual 1 minute = luck 2 hours
actual 1 second = luck 2 minutes
```

이를 하나의 정확한 식으로 표현하면 다음과 같다.

```text
luckDurationSeconds = elapsedSeconds * 120
```

그 후 `360일 → 30일 → 1일 → 1시간 → 1분 → 1초` 순으로 몫과 나머지를 구해 `years, months, days, hours, minutes, seconds`로 정규화한다.

주의: 이 기간의 `year`와 `month`는 처음에는 360일·30일 환산 단위지만, 첫 교운 계산에서는 아래 규칙에 따라 현지 달력의 년과 월로 더한다.

### 9.5 첫 교운시점

기본 프로필은 출생 현지시각에 환산기간을 다음 순서로 더한다.

1. years
2. months
3. days
4. hours
5. minutes
6. seconds

월말 클램프 규칙은 Java `LocalDateTime.plusYears().plusMonths()`와 같이 목표 월에 같은 일이 없으면 그 달의 마지막 날을 사용한다. 시간대가 DST 전환을 포함하면 달력 연산 후 지역 시간대 규칙을 다시 적용하며, gap/overlap 정책을 결과에 기록한다.

`elapsedSeconds * 120`을 실제 출생 instant에 그대로 더하는 방식은 다른 결과를 내므로 기본 프로필에서 사용하지 않는다.

출생시각이 없으면 현지 정오 `12:00`를 계산 기준으로 사용한다. 이때 기산기간과 첫 교운시점은 모두 추정값으로 표시하고 결과 경고에 해당 정책을 기록한다.

### 9.6 대운 간지

- 첫 대운은 출생 월주의 다음 간지(순행) 또는 이전 간지(역행)다.
- 각 대운은 60갑자에서 같은 방향으로 한 칸씩 이동한다.
- 교운시점은 첫 교운 현지시각에 달력상 10년씩 더한다.

## 10. 오류 및 경고

| 코드 | 조건 |
|---|---|
| `INVALID_LOCAL_TIME` | 해당 시간대에 존재하지 않는 시각 |
| `AMBIGUOUS_LOCAL_TIME` | 중복 시각인데 오프셋 선택이 없음 |
| `EPHEMERIS_OUT_OF_RANGE` | 절입 데이터 지원 범위 밖 |
| `UNLOCKED_RULE` | 확정되지 않은 규칙으로 계산 요청 |
| `TERM_TIMEZONE_UNKNOWN` | 절입 원자료의 시간대 불명 |
| `CALENDAR_ADD_CLAMPED` | 월말 덧셈에서 날짜가 보정됨 |
