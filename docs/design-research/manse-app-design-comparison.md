# 만세력 앱 자료화면 및 디자인 비교 분석

- 문서 버전: 1.0
- 작성일: 2026-08-18
- 대상: Taildrop으로 전달된 모바일 만세력 앱 화면 16장
- 목적: 만세력 계산 엔진 이후 제품 UI·UX를 설계하기 위한 참고 자료 보존
- 원본 보존: `docs/design-research/assets/manse-apps/`
- 무결성 목록: `docs/design-research/manse-app-screen-manifest.json`

## 1. 문서 사용 시 주의

이 문서는 제공된 정지 화면만을 기준으로 분석했다. 실제 앱을 조작하지 않았으므로 터치, 스와이프, 검색, 설정 등의 동작은 화면에 나타난 단서로만 추정했다.

화면에는 이름과 생년월일시가 포함되어 있다. 외부 공유용 문서나 공개 저장소로 옮길 때에는 반드시 개인정보를 가리거나 테스트용 가명 데이터로 교체해야 한다.

## 2. 전체 자료 구성

| 분류 | 화면 수 | 디자인 성격 | 주요 자료 |
|---|---:|---|---|
| 앱 A | 3 | 전통 고밀도형 | 원국, 신살, 합충, 대운, 세운, 월운 |
| 앱 B | 2 | 파스텔 요약형 | 원국 요약, 대운, 일진·행운 비교 |
| 앱 C | 4 | 전문가 격자형 | 원국 관계선, 기술 항목, 대운·세운·월운·일운 |
| 앱 D | 7 | 현대 카드·차트형 | 지역시 보정, 관계, 신살, 오행·십성, 신강, 용신, 운 |

네 앱 모두 원국·대운·세운을 제공하지만 정보의 우선순위와 표현 방식은 크게 다르다.

- 앱 A는 한 화면에 최대한 많은 정보를 넣는다.
- 앱 B는 원국과 현재 운을 간결하게 보여준다.
- 앱 C는 명리 전문가가 표를 훑는 방식을 따른다.
- 앱 D는 초보자에게 단계적으로 설명하고 차트로 해석한다.

## 3. 앱 A — 전통 고밀도형

### 3.1 자료화면

#### A-01 원국 전체

![앱 A 원국 전체](assets/manse-apps/app-a-01-natal-overview.jpeg)

관찰 내용:

- 출생정보 아래에 시주·일주·월주·년주를 한 번에 배치한다.
- 천간과 지지를 원색 정사각형으로 크게 표현한다.
- 십성, 지장간, 12운성, 사중금, 간합수, 송백목, 노중화 등을 같은 열에 배치한다.
- 합·형·방합·삼합·암합·귀문 등 관계를 노란 영역에 텍스트와 화살표로 표시한다.
- 신살, 형충회합 등 표시 항목을 체크박스로 제어하는 것으로 보인다.

#### A-02 대운·세운

![앱 A 대운과 세운](assets/manse-apps/app-a-02-luck-year-timeline.jpeg)

관찰 내용:

- `전통나이(대운수: 1, 순행)`를 화면에 명시한다.
- 10년 단위 대운을 나이, 십성, 간지, 12운성, 신살과 함께 가로로 배열한다.
- 선택 대운은 파란 외곽선으로 표시한다.
- 대운 아래에 세운을 같은 시각 문법으로 이어 붙인다.

#### A-03 세운·월운

![앱 A 세운과 월운](assets/manse-apps/app-a-03-year-month-timeline.jpeg)

관찰 내용:

- 세운과 월운의 간지·십성·12운성·신살을 동일한 열 구조로 보여준다.
- 현재 연도와 월을 빠르게 훑을 수 있지만 작은 화면에서는 오른쪽 열이 잘린다.
- 토정비결, 당사주, 신살 나침반 등 주변 기능으로 이동하는 버튼이 하단에 있다.

### 3.2 장점

1. **전문가용 데이터 밀도가 가장 높다.** 원국에서 대운·세운·월운까지 한 흐름으로 검토할 수 있다.
2. **간지 자체는 잘 보인다.** 큰 한자와 강한 색 대비 덕분에 네 기둥을 즉시 확인할 수 있다.
3. **열 단위 비교가 가능하다.** 각 대운과 세운에 해당하는 십성·12운성·신살을 수직으로 읽을 수 있다.
4. **현재 선택 상태가 존재한다.** 파란 테두리를 통해 어느 대운을 보고 있는지 알 수 있다.
5. **순행과 대운수를 노출한다.** 계산 결과의 핵심 일부를 첫 화면 가까이에서 확인할 수 있다.

### 3.3 단점

1. **정보 계층이 평평하다.** 중요한 원국, 보조적인 신살, 해석용 관계가 비슷한 강도로 보인다.
2. **시각적 소음이 크다.** 굵은 검은 테두리, 원색, 많은 구분선이 동시에 경쟁한다.
3. **행과 열의 대응을 잃기 쉽다.** 신살과 관계 텍스트가 줄바꿈되면서 어떤 기둥에 속하는지 모호해진다.
4. **반응형 화면에 취약하다.** 대운·세운 열이 잘리거나 글자가 겹치기 쉽다.
5. **색상 의존도가 높다.** 색각 이상, 흑백 출력, 저품질 화면에서 오행 구분이 약해질 수 있다.
6. **정확한 교운 근거가 없다.** `대운수 1`은 보이지만 절입시각, 시간차, 첫 교운 일시는 보이지 않는다.
7. **초보자 진입점이 없다.** 무엇을 먼저 읽어야 하는지 안내하지 않는다.

### 3.4 채택할 요소

- 전문가 모드의 고밀도 표
- 원국·대운·세운·월운에 동일한 열 문법 적용
- 현재 선택 대운의 명확한 강조
- 순행·역행의 상시 노출

### 3.5 피할 요소

- 검은 외곽선과 원색을 모든 항목에 동일하게 적용하는 방식
- 신살을 기본 화면에 모두 펼쳐놓는 방식
- 화면 폭보다 많은 열을 축소 글꼴로 해결하는 방식

## 4. 앱 B — 파스텔 요약형

### 4.1 자료화면

#### B-01 원국과 대운

![앱 B 원국과 대운](assets/manse-apps/app-b-01-natal-overview.jpeg)

관찰 내용:

- 출생정보와 네 기둥, 대운을 첫 화면 안에 배치한다.
- 천간과 지지는 둥근 사각형이며 지지의 한글 음을 함께 표시한다.
- 일간을 `본원`으로 별도 강조한다.
- 대운은 10개를 한 줄로 압축해 나이와 간지를 동시에 보여준다.
- 명식·일진·달력·메모 관리의 하단 탐색 메뉴가 있다.

#### B-02 일진·행운 상세

![앱 B 일진과 행운](assets/manse-apps/app-b-02-daily-luck-detail.jpeg)

관찰 내용:

- 원국 위에 시진·일진·절운·세운·대운을 같은 카드 문법으로 배치한다.
- 현재 날짜의 운을 원국과 직접 비교할 수 있다.
- `운세 보기`, `메모 작성`처럼 다음 행동이 명확하다.

### 4.2 장점

1. **원국 파악 속도가 가장 빠르다.** 적당한 여백과 단순한 블록으로 네 기둥이 분명하다.
2. **초보자와 전문가 사이의 균형이 좋다.** 십성·12운성을 제공하면서 화면을 과도하게 채우지 않는다.
3. **일간 중심성을 안내한다.** `본원` 표시로 사용자의 시선이 자연스럽게 일주로 간다.
4. **탐색 구조가 익숙하다.** 하단 탭과 분명한 행동 버튼은 모바일 사용 방식에 잘 맞는다.
5. **원국과 행운의 비교가 자연스럽다.** 같은 시각 언어를 사용해 학습 비용을 줄인다.

### 4.3 단점

1. **회색 글자의 대비가 낮다.** 부가 정보가 너무 옅어 밝은 환경이나 저시력 사용자에게 불리하다.
2. **대운을 지나치게 압축한다.** 10개의 운과 나이, 십성, 12운성을 한 줄에 넣어 글자가 작다.
3. **상호작용 단서가 약하다.** 대운을 터치하거나 좌우 이동할 수 있는지 정지 화면만으로 분명하지 않다.
4. **현재 대운 강조가 약하다.** 사용자가 현재 위치를 다시 계산해야 할 수 있다.
5. **계산 근거가 보이지 않는다.** 지역시, 절입시각, 교운 일시를 확인하기 어렵다.
6. **구독 안내가 작업 흐름에 들어온다.** 핵심 명식 화면에서 제품 판매 요소가 시선을 분산한다.

### 4.4 채택할 요소

- 우리 앱 기본 원국 화면의 뼈대
- 일간을 중심으로 한 시각적 강조
- 원국·대운·행운에서 반복되는 동일 카드 문법
- 명식·운·달력·메모의 명확한 정보구조

### 4.5 개선해서 채택할 요소

- 대운 10개 전체를 축소하지 않고 현재 대운 전후 2~3개를 우선 표시
- 현재 대운을 테두리뿐 아니라 `현재` 텍스트와 기간으로 함께 표시
- 회색 텍스트 대비를 WCAG 기준에 맞게 강화

## 5. 앱 C — 전문가 격자형

### 5.1 자료화면

#### C-01 원국과 관계선

![앱 C 원국과 관계선](assets/manse-apps/app-c-01-natal-relations.jpeg)

관찰 내용:

- 형·충·합·파·해·귀문·원진을 아이콘 범례로 제공한다.
- 기둥 사이 관계를 선과 노드로 직접 연결한다.
- 천간과 지지를 큰 정사각형으로 배치한다.

#### C-02 기술 정보

![앱 C 기술 정보](assets/manse-apps/app-c-02-technical-details.jpeg)

관찰 내용:

- 12운성, 12신살, 신살, 공망, 당사주, 오행 분석을 섹션 막대로 분리한다.
- 상담가가 원자료를 연속해서 검토하기 좋은 문서형 구성이다.

#### C-03 대운과 세운

![앱 C 대운과 세운](assets/manse-apps/app-c-03-luck-year-timeline.jpeg)

관찰 내용:

- 대운과 세운을 같은 격자 구조로 배열한다.
- 간지, 십성, 신살, 12운성을 열 단위로 비교한다.
- 화면 폭보다 많은 열이 존재하며 양옆 일부가 잘린다.

#### C-04 월운과 일운

![앱 C 월운과 일운](assets/manse-apps/app-c-04-month-day-timeline.jpeg)

관찰 내용:

- 월운과 일운까지 동일한 표 문법을 유지한다.
- 하단에 사용자 메모 기능이 있다.

### 5.2 장점

1. **전문가의 비교 방식과 가깝다.** 대운·세운·월운·일운을 같은 규격으로 훑을 수 있다.
2. **관계의 존재를 공간적으로 보여준다.** 합충 관계를 텍스트 목록보다 직관적으로 발견할 수 있다.
3. **큰 간지와 명확한 섹션 제목을 사용한다.** 데이터 위치를 다시 찾기 쉽다.
4. **기술 정보 누락이 적다.** 신살·공망·당사주 등 다양한 학파 정보를 수용한다.
5. **상담 기록에 유리하다.** 메모가 운의 상세 화면과 연결되어 있다.

### 5.3 단점

1. **관계선이 복잡해지면 의미가 흐려진다.** 어느 선이 어떤 범례인지 계속 상단을 확인해야 한다.
2. **표가 화면 폭을 초과한다.** 열 축소와 잘림으로 현재 선택 위치를 놓치기 쉽다.
3. **전문 용어를 설명하지 않는다.** 초보자는 데이터가 많아도 의미를 해석할 수 없다.
4. **세로 스크롤이 길다.** 모든 기술 항목을 기본 상태에서 펼쳐 놓는다.
5. **도구형 인상이 강하다.** 보라색 헤더와 짙은 회색 섹션 막대가 정보의 무게를 더한다.
6. **계산 출처가 드러나지 않는다.** 원국과 운의 값은 많지만 어떤 시간 보정과 절입 데이터를 사용했는지 모른다.

### 5.4 채택할 요소

- 전문가 모드의 대운·세운·월운·일운 공통 격자
- 합충 관계를 별도 탭에서 시각화하는 방식
- 운 단위 메모 기능
- 기술 항목의 명확한 섹션 분리

### 5.5 개선해서 채택할 요소

- 관계선을 클릭하면 관계명과 참여 기둥을 텍스트로 표시
- 현재 선택 열을 상하 전체에 걸쳐 배경색으로 강조
- 좌우 고정 헤더와 스크롤 위치 표시 사용
- 신살과 부가 정보는 기본 접힘 상태로 제공

#### D-07 연운과 월운

![앱 D 연운과 월운](assets/manse-apps/app-d-07-annual-monthly-luck.jpeg)

관찰 내용:

- 선택한 대운 아래에서 연운과 월운을 같은 카드 방식으로 탐색한다.
- 현재 연도를 흰색 큰 카드로 강조한다.

### 6.2 장점

1. **시각적 완성도가 가장 높다.** 여백, 카드, 둥근 모서리, 제한된 색상으로 정보 계층이 분명하다.
2. **계산 입력의 투명성이 상대적으로 높다.** 출생지역과 지역시 보정 결과를 첫 화면에서 확인할 수 있다.
3. **복잡한 정보를 단계적으로 공개한다.** 원국, 관계, 신살, 오행, 용신, 대운을 별도 섹션으로 나눈다.
4. **초보자의 이해를 돕는다.** 차트, 퍼센트, 간단한 상태 문구를 사용한다.
5. **모바일 탐색에 적합하다.** 탭, 카드, 좌우 슬라이드 구조가 손가락 조작에 맞는다.
6. **관계 강조가 명확하다.** 선택된 관계의 글자만 배경색으로 강조한다.

### 6.3 단점

1. **계산과 해석이 너무 일찍 섞인다.** 만세력 원자료를 확인하기 전에 과다·적정·용신 같은 해석 결과가 제시된다.
2. **퍼센트가 과도한 정밀성을 암시한다.** 오행 37.5%처럼 표시하면 학파별 가중치가 객관적 측정값처럼 보일 수 있다.
3. **전문가의 빠른 비교에는 느리다.** 카드가 크고 화면이 길어 여러 운을 한꺼번에 보기 어렵다.
4. **광고가 분석 흐름을 끊는다.** 섹션 사이의 배너가 맥락을 분리한다.
5. **대운의 정확한 시작은 여전히 없다.** 대운수와 나이는 보이지만 절입시각과 교운 일시는 드러나지 않는다.
6. **차트 접근성이 부족할 수 있다.** 색상이나 면적만으로 값의 차이를 전달하는 부분이 있다.
7. **보정 근거가 한 단계 부족하다.** `-32분`은 보여주지만 기준 경도와 산식은 보이지 않는다.

### 6.4 채택할 요소

- 프로필에서 표준시와 보정시를 함께 보여주는 방식
- 기본 화면과 상세 분석의 단계적 정보 공개
- 관계별 탭과 참여 글자 강조
- 현재 대운·세운의 큰 카드 강조
- 차분한 색상과 충분한 터치 영역

### 6.5 제한적으로 채택할 요소

- 오행·십성 차트는 해석 모드에서만 사용
- 모든 퍼센트에 계산 공식과 가중치 프로필을 연결
- 광고나 부가 콘텐츠는 계산 확인 흐름과 분리

## 7. 비교 평가

점수는 제공된 화면에 대한 상대 평가이며 5점이 가장 좋다.

| 평가 항목 | 앱 A | 앱 B | 앱 C | 앱 D |
|---|---:|---:|---:|---:|
| 원국 파악 속도 | 3 | 5 | 4 | 4 |
| 전문가용 정보량 | 5 | 3 | 5 | 2 |
| 초보자 친화성 | 1 | 4 | 1 | 5 |
| 대운·세운 탐색 | 4 | 4 | 4 | 4 |
| 시각적 완성도 | 2 | 4 | 3 | 5 |
| 계산 근거 투명성 | 2 | 1 | 1 | 3 |
| 작은 화면 가독성 | 2 | 4 | 2 | 4 |
| 접근성 잠재력 | 2 | 3 | 2 | 3 |

### 핵심 결론

- 기본 원국 화면의 균형은 앱 B가 가장 좋다.
- 전문가가 한 번에 검토할 수 있는 정보량은 앱 A와 C가 가장 많다.
- 모바일 제품의 현대적 정보 계층은 앱 D가 가장 좋다.
- 네 앱 모두 정밀 교운시점과 계산 과정을 충분히 보여주지 않는다.

## 8. 공통으로 발견된 문제

### 8.1 대운수와 정확한 교운시점 혼용

화면들은 `대운수 1`, `2세`, `11세` 같은 요약값을 보여주지만 다음 정보는 제공하지 않는다.

- 순행·역행 판정에 사용한 연간
- 기준 절기와 절입시각
- 출생 instant와 절입 instant의 시간차
- `3일 = 1년` 환산 과정
- 첫 교운의 정확한 날짜와 시각
- 달력식 덧셈 또는 총일수 덧셈 여부

이 때문에 앱 사이에 1세·2세 차이가 나타나도 사용자가 원인을 확인할 수 없다.

### 8.2 계산 프로필 부재

다음 정책이 화면에 보이지 않거나 일부만 보인다.

- 표준시와 진태양시
- 지역 경도 보정
- 서머타임과 역사 시간대
- 자시 일진 경계
- 절입 데이터 출처
- 대운 기산 방식

### 8.3 색상 의존

네 앱 모두 오행을 색으로 구분한다. 색은 보조 수단으로 유용하지만 반드시 `목·화·토·금·수` 또는 한글 음을 함께 표시해야 한다.

### 8.4 모바일 폭 문제

대운·세운처럼 열이 많은 정보는 다음 중 하나가 필요하다.

- 현재 운 중심의 부분 표시
- 명시적인 가로 스크롤
- 고정 행·열 헤더
- 전체 표 보기 모드
- 선택 열의 세로 배경 강조

작은 글꼴로 10개 열을 억지로 맞추는 방식은 사용하지 않는다.

### 8.5 원자료와 해석의 혼합

원국, 절입, 교운은 계산 결과이고 신강·용신·신살 평가는 해석 규칙이다. 앱 구조에서도 두 층을 분리해야 한다.

## 9. 우리 앱의 권장 방향

### 9.1 조합 원칙

- 원국 첫 화면: 앱 B의 간결한 구조
- 시간 보정과 계산 투명성: 앱 D의 프로필 표시를 확장
- 전문가 표: 앱 A와 C의 고밀도 표
- 관계 탐색: 앱 D의 탭 방식과 앱 C의 관계선 방식을 결합
- 해석 시각화: 앱 D의 카드·차트를 별도 해석 모드에서 사용

### 9.2 정보구조

```text
출생정보
├─ 원국
├─ 대운
├─ 세운·월운·일운
├─ 계산 근거
└─ 해석
```

`계산 근거`는 부가 도움말이 아니라 핵심 탭이어야 한다.

### 9.3 기본 모드와 전문가 모드

#### 기본 모드

```text
원국 네 기둥
→ 현재 대운
→ 다음 교운 날짜
→ 현재 세운
→ 계산 기준 요약
```

#### 전문가 모드

```text
원국 전체
→ 지장간·십성·12운성
→ 합충형파해
→ 대운·세운·월운·일운 격자
→ 절입·시간대·교운 산술
```

### 9.4 대운 화면 필수 정보

```text
방향: 순행
기준 절기: 청명
절입: 1986-04-05 11:06:07 KST
출생과의 차이: 2일 19시간 41분 7초
환산기간: 11개월 8일 10시간 14분
첫 교운: 1987-03-11 01:39
다음 교운: 2027-03-11 01:39
계산 프로필: kr-traditional-v1
```

사용자가 요약값을 터치하면 위 전체 계산이 펼쳐져야 한다.

### 9.5 원국 화면 권장 레이아웃

1. 상단 프로필 카드
   - 양력·음력
   - 표준시, 지역시 또는 진태양시
   - 출생지역과 시간대
   - 적용한 계산 프로필
2. 네 기둥 카드
   - 시주·일주·월주·년주
   - 천간·지지와 한글 음
   - 일간 명확한 강조
3. 현재 운 요약
   - 현재 대운과 적용 기간
   - 다음 교운까지 남은 기간
   - 현재 세운
4. 상세 탭
   - 지장간·십성·12운성
   - 관계
   - 신살
   - 계산 근거

### 9.6 접근성 원칙

- 색상과 함께 오행명 또는 글자 음을 표시한다.
- 본문과 배경의 대비를 WCAG AA 이상으로 맞춘다.
- 한자를 확대해도 행과 열이 무너지지 않게 한다.
- 터치 영역은 최소 44×44pt 수준을 확보한다.
- 현재 선택은 색상, 테두리, `현재` 텍스트를 함께 사용한다.
- 차트에는 숫자 표와 텍스트 설명을 함께 제공한다.

## 11. 최종 디자인 판단

한 앱을 그대로 모방하는 것은 적합하지 않다.

- 앱 A와 C의 정보량은 전문가에게 유용하지만 기본 화면으로는 과하다.
- 앱 D의 현대적 구성은 좋지만 계산과 해석을 혼합하고 차트가 원자료를 가린다.
- 앱 B의 원국 화면이 가장 안정적인 출발점이다.

따라서 우리 앱은 **앱 B의 원국 구조를 기본 골격으로 하고, 앱 D의 시간 보정 표시와 단계적 정보 공개를 결합하며, 앱 A·C의 표를 전문가 모드로 제공하는 방향**을 채택한다.

가장 중요한 차별점은 기존 화면에서 빠져 있는 다음 문장으로 요약된다.

> 모든 간지와 교운 결과에 대해 “왜 이 값이 나왔는가”를 사용자가 확인할 수 있어야 한다.
