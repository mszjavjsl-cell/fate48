# 만세력 검증용 정답 사례집 v0.1.0-draft

## 1. 정답 등급

| 상태 | 의미 |
|---|---|
| `locked` | 권위 데이터와 독립 구현으로 확인되어 회귀 테스트의 필수 정답으로 사용 |
| `provisional` | 계산 규칙과 산술은 확인했지만 천문 데이터 또는 학파 정책이 아직 미확정 |
| `exploratory` | 쟁점 발견용 사례이며 정답으로 사용하지 않음 |

현재 사례는 모두 `provisional`이다. 절입 공급원과 일주 기준을 확정한 뒤 `locked`로 승격한다.

## 2. 대운 산술 사례

### GC-LUCK-001 — 1989년 여성, 음년 순행

**상태:** `provisional`

**입력 및 프로필**

- 양력: 1989-05-13 07:15:00
- 시간대: Asia/Seoul (UTC+09:00)
- 성별: 여성
- 진태양시: 미적용
- 년주: 己巳
- 월주: 己巳
- 기산: 실제 3일 = 대운 1년, 달력식 덧셈

**판정**

- 己는 음간
- 음년 여성 → 순행
- 다음 절: 망종
- 잠정 망종: 1989-06-06 02:05:14 +09:00

**산술**

```text
elapsed = 1989-06-06 02:05:14 - 1989-05-13 07:15:00
        = 23일 18시간 50분 14초

23일  = 7년 8개월
18시간 = 3개월
50분  = 4일 4시간
14초  = 28분

converted = 7년 11개월 4일 4시간 28분
first transition = 1997-04-17 11:43:00 +09:00
```

**대운**

| 차수 | 대운 | 교운시점 |
|---:|---|---|
| 1 | 庚午 | 1997-04-17 11:43 |
| 2 | 辛未 | 2007-04-17 11:43 |
| 3 | 壬申 | 2017-04-17 11:43 |
| 4 | 癸酉 | 2027-04-17 11:43 |
| 5 | 甲戌 | 2037-04-17 11:43 |

**잠금 조건**

- 망종 instant를 채택한 천문 데이터로 재검증한다.
- 절입 원자료의 시간대가 KST임을 메타데이터로 보존한다.

### GC-LUCK-003 — 1976년 역행 산술

**상태:** `provisional`

이 사례는 성별과 순역 판정 전체가 아니라 **역행 시간차와 환산 산술**을 검증한다.

- 출생: 1976-01-04 18:00:00
- 시간대: Asia/Seoul
- 방향: 역행(테스트에 강제 지정)
- 이전 절: 대설
- 잠정 대설: 1975-12-08 02:46:11 +09:00

```text
elapsed = 27일 15시간 13분 49초
converted = 9년 2개월 16일 3시간 38분
first transition = 1985-03-20 21:38:00 +09:00
```

## 3. 경계 사례 — 구현 전에 반드시 추가

다음은 절입 데이터와 일주 기준을 잠근 후 생성한다.

- `GC-YEAR-001`: 입춘 1초 전과 정확히 입춘, 입춘 1초 후
- `GC-MONTH-001`: 각 12절 1초 전과 정확히 절입, 1초 후
- `GC-DAY-001`: 22:59:59, 23:00:00, 23:59:59, 00:00:00
- `GC-HOUR-001`: 00:59:59/01:00:00 및 22:59:59/23:00:00
- `GC-TZ-001`: 같은 UTC instant를 Asia/Seoul과 Asia/Shanghai로 표시
- `GC-DST-001`: DST gap과 overlap
- `GC-LEAP-001`: 2월 29일 출생과 달력식 년 덧셈
- `GC-LUCK-BOUNDARY-001`: 출생 instant와 절입 instant가 정확히 같은 경우
- `GC-REVERSE-001`: 역행의 이전 절 선택
- `GC-LUNAR-001`: 윤달 전후 양·음력 변환

## 4. 독립 검증 정책

`locked` 승격에는 다음이 필요하다.

1. 절입 instant를 권위 있는 천문 계산 또는 역서로 확인한다.
2. 원국 네 기둥을 서로 다른 두 구현에서 비교한다.
3. 기대값을 산출한 코드와 실제 엔진 테스트 코드가 같은 함수를 공유하지 않게 한다.
4. 수기 산술을 사례집에 남긴다.
5. 시간대, tzdb, 천문 모델, 프로필 버전을 기록한다.
